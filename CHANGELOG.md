# Changelog

All notable changes to this project will be documented in this file.

## v1.0.0 - Initial release

- Provide a Docker-based GitHub Action that runs PR review checks and can post comments/suggestions on pull requests.
- Inputs:
  - `github_token` (required): GitHub token for API access.
  - `config` (optional): Path to config file in the repository.
- Usage examples added to README.

No breaking changes.
